## Contexte

Dans le cadre de ma première année de BTS SIO, option SISR, j’ai réalisé un portfolio professionnel afin de présenter mes compétences, mes projets et les travaux effectués pendant ma formation. Ce site a pour objectif de montrer mon évolution dans le domaine des systèmes et des réseaux, et de permettre à un jury d’examen ou à un recruteur de consulter mes réalisations.

## Conditions et moyens

J’ai réalisé ce projet individuellement dans le cadre de ma formation en BTS SIO, option SISR. J’ai utilisé un navigateur web pour accéder à GitHub, gérer les fichiers de mon dépôt et personnaliser mon portfolio. Le site est hébergé gratuitement avec GitHub Pages et généré à partir du modèle fourni, utilisant Jekyll. Aucun logiciel supplémentaire n’a été nécessaire.

## Description de l'activité

- Création du dépôt GitHub à partir du modèle.

- Activation de GitHub Pages.

- Modification de _config.yml.

- Personnalisation de la page d'accueil.

- Vérification du site publié.

## Productions et preuves

- https://rafaelpicard.github.io/Portfolio/
- Le dépôt et son historique des modifications.
- Le score d'accessibilité relevé.

## Ce que j'en retiens

Ce projet m'a permis de découvrir comment publier un site web avec GitHub Pages et de personnaliser un portfolio professionnel. J'ai appris à modifier les fichiers du site et à vérifier que mes changements étaient bien publiés. Je pourrai maintenant enrichir progressivement mon portfolio avec les projets réalisés pendant mon BTS SIO, option SISR.
